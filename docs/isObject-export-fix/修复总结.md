# isObject 导出错误修复总结

## 问题描述

项目运行时出现错误：
```
The requested module '@pengzhanbo/utils' does not provide an export named 'isObject'
```

## 问题原因

1. `vite-plugin-mock-dev-server@1.8.0` 的代码中使用了 `isObject` 函数
2. 从 `@pengzhanbo/utils@1.2.0` 版本开始，`isObject` 函数被重命名为 `isPlainObject`
3. 版本不匹配导致导入失败

## 解决方案

升级 `vite-plugin-mock-dev-server` 到最新版本 `2.0.7`，该版本已经修复了这个问题：
- 新版本使用 `isPlainObject` 替代了 `isObject`
- 新版本依赖 `@pengzhanbo/utils@^2.1.2`，该版本正确导出了 `isPlainObject`

## 修改内容

### package.json

```json
{
  "devDependencies": {
    "vite-plugin-mock-dev-server": "^2.0.7"  // 从 1.8.0 升级到 2.0.7
  }
}
```

## 验证

- ✅ 升级后 `vite-plugin-mock-dev-server` 不再使用 `isObject`
- ✅ 新版本正确使用 `isPlainObject` 从 `@pengzhanbo/utils` 导入
- ✅ 依赖版本匹配，问题已解决
