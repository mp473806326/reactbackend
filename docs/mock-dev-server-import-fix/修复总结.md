# vite-plugin-mock-dev-server 导入错误修复总结

## 问题描述

运行 `npm run dev` 时出现错误：

```
SyntaxError: The requested module 'file:///D:/test/react-pc-template/node_modules/vite-plugin-mock-dev-server/dist/index.mjs' does not provide an export named 'default'
```

## 问题原因

在 `vite.config.ts` 中使用了默认导入方式：

```typescript
import mockDevServerPlugin from "vite-plugin-mock-dev-server";
```

但是 `vite-plugin-mock-dev-server@2.0.7` 只提供命名导出（named export），不提供默认导出（default export）。该包的导出方式为：

```javascript
export { mockDevServerPlugin, ... }
```

## 解决方案

将默认导入改为命名导入：

### 修改前

```typescript
import mockDevServerPlugin from "vite-plugin-mock-dev-server";
```

### 修改后

```typescript
import { mockDevServerPlugin } from "vite-plugin-mock-dev-server";
```

## 修改内容

### vite.config.ts

- 第 3 行：将默认导入改为命名导入
