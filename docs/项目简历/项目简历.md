React PC Template 后台管理系统项目简历

项目概述
React PC Template 是一个基于 React 技术栈构建的现代化后台管理系统模板项目。该项目提供了完整的后台管理解决方案，包括用户认证、动态路由、权限管理、数据可视化等核心功能模块。

技术栈详解

核心框架
React 18.3
采用最新的 React 18.3 版本，充分利用 React Hooks 进行函数式组件开发，提升代码可维护性和开发效率。使用函数组件和 Hooks 实现状态管理和生命周期管理。

TypeScript 5.4
全面采用 TypeScript 进行类型约束，提供完整的类型定义系统。通过严格的类型检查，减少运行时错误，提升代码质量和开发体验。配置了完整的类型声明文件，包括全局类型、组件类型、路由类型和用户类型。

构建工具
Vite 5.4
使用 Vite 作为现代化构建工具，提供极速的开发服务器启动和热模块替换功能。配置了路径别名、代码分割、资源优化等构建策略，支持生产环境的代码压缩和优化。

状态管理
Zustand 4.5
采用轻量级状态管理库 Zustand 进行全局状态管理。相比 Redux 更加简洁，API 设计直观，性能优异。项目中用于管理用户信息、路由配置、主题切换等全局状态。

Immer 10.1
结合 Immer 实现不可变数据更新，简化复杂状态操作，提升代码可读性和维护性。

UI 组件库
Ant Design 5.24
使用 Ant Design 5.24 作为主要 UI 组件库，提供丰富的企业级组件。包括表格、表单、布局、导航、数据展示等完整组件生态。采用 Ant Design 的主题定制能力，支持深色模式切换。

Ant Design Charts 2.2
集成 Ant Design Charts 用于数据可视化，支持多种图表类型，包括柱状图、折线图、散点图、面积图等，满足后台管理系统的数据展示需求。

Ant Design Icons 4.8
使用 Ant Design Icons 提供丰富的图标库，支持 SVG 图标自定义和主题适配。

路由管理
React Router DOM 6.29
采用 React Router DOM 6.29 实现单页应用路由管理。实现了动态路由配置、路由懒加载、路由权限控制等功能。支持嵌套路由和路由守卫，确保系统的安全性。

HTTP 请求
Axios 1.7
使用 Axios 作为 HTTP 请求库，封装了统一的请求拦截器和响应拦截器。实现了自动 token 注入、请求错误处理、响应数据格式化等功能。配置了请求超时、错误重试等机制。

工具库
Lodash 4.17
集成 Lodash 工具库，提供常用的工具函数，简化数组、对象等数据结构的操作。

Day.js 1.11
使用 Day.js 进行日期时间处理，相比 Moment.js 更加轻量，API 设计简洁，支持国际化。

Ahooks 3.8
使用 Ahooks 提供丰富的 React Hooks 工具集，包括 useRequest、useDebounce、useThrottle 等常用 Hooks，提升开发效率。

样式处理
Sass 1.85
采用 Sass 作为 CSS 预处理器，支持变量、嵌套、混合等高级特性。使用 CSS Modules 实现样式作用域隔离，避免样式冲突。配置了全局样式和主题样式文件。

开发工具
ESLint 8.57
配置了完整的 ESLint 规则，包括 TypeScript ESLint 插件、React Hooks 插件等，确保代码质量和一致性。

Prettier 3.2
集成 Prettier 进行代码格式化，统一代码风格，提升代码可读性。

Mock 数据
MockJS 1.1
使用 MockJS 生成模拟数据，支持随机数据生成和模板定义。

Vite Plugin Mock Dev Server 2.0
集成 Vite Mock 插件，在开发环境中提供 Mock 服务，无需启动后端服务即可进行前端开发和调试。

其他插件
Vite Plugin SVG Icons 2.0
配置 SVG 图标插件，支持 SVG 图标的自动导入和按需加载，优化图标使用方式。

Vite Plugin Remove Console 2.2
生产环境自动移除 console 语句，减少代码体积，提升性能。

项目特性

架构设计
采用模块化架构设计，代码结构清晰，职责分明。包含 API 层、组件层、视图层、工具层、状态管理层等完整的分层架构。

动态路由
实现了基于后端配置的动态路由系统，支持路由权限控制和菜单动态生成。路由配置支持嵌套结构，可灵活配置菜单层级。

权限管理
实现了完整的权限管理体系，包括路由权限、菜单权限等。通过路由守卫确保用户只能访问有权限的页面。

组件封装
封装了常用业务组件，包括表格组件、表单组件、按钮组件等，提升代码复用性和开发效率。

主题切换
支持明暗主题切换功能，使用 Ant Design 的主题定制能力，提供良好的用户体验。

代码规范
配置了完整的代码规范工具，包括 ESLint 和 Prettier，确保团队协作的代码一致性。

开发体验
配置了路径别名、热模块替换、自动打开浏览器等开发工具，提供流畅的开发体验。
